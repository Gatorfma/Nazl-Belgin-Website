# nazlibelgin.com
# The site is a single page; everything below the root is assets.
#
# Note on formatting: a blank line ends a record, so the directives inside each
# group below follow their User-agent lines with no blank line between them.
# There is also no blanket "Allow: /" — everything is crawlable by default, and
# parsers that take the first matching rule rather than the longest one would
# treat such a line as overriding the Disallow rules.
#
# Repository scaffolding that GitHub Pages serves but which is not part of the
# site is kept out of search results, so SQL files and build scripts do not
# surface under the artist's name.
User-agent: *
Disallow: /supabase/
Disallow: /tools/
Disallow: /docs/
Disallow: /.claude/
